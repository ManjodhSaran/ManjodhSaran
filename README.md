- **Real-time tracking, end to end.** An offline-first driver app with a 14-day location buffer, a GPS ingest service that rejects bad fixes and smooths the rest, and the live map and ETAs dispatchers work from.
- **The AI layer.** A chat assistant that answers questions about a fleet's loads and money, an operations dashboard of exceptions, and automatic parsing of proof-of-delivery documents.
- **Two apps in the stores.** [Truxo Tracker](https://apps.apple.com/us/app/truxo-tracker/id6748335865) for drivers (offline document and chat outbox, document scanning, pre-trip inspections) and [Book CRM](https://apps.apple.com/us/app/book-crm/id6803867238) for the sales team.
- **The parts that aren't code.** Module docs, tester handoffs and QA briefs for all of the above, and the weekly leadership meeting system the team runs on.
